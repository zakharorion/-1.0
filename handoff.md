# Handoff — OFF Сянка лендинг

> Передача проекта. Последнее обновление: 2026-06-19. HEAD: `d5d2f13`.

## 🎯 Цель
Редизайн одностраничного лендинга бренда **OFF Сянка** (ленивая протеиновая овсянка, 10 вкусов)
в визуальном языке **Gigantic** — «панк-рок обёртка на кремовой бумаге»:
- Палитра монохром + один красный: ink `#231f20` на cream `#f0ede7`, акцент blast-red `#ff634b`
  (только бренд-точка, бейджи, бегущая строка, плашка футера).
- Огромная типографика (Inter — кириллический заменитель Neue Haas Grotesk), широкий трекинг.
- Плоско: 0px радиус, без теней/градиентов; жёсткие цветовые переходы между секциями.
Работаем **посекционно**, по запросу пользователя.

## ✅ Текущее состояние
Сделаны и согласованы: бегущая строка, хэдер (двухрядное меню + бургер), герой, тёмная секция
«Десять вкусов» (авто-карусель). Остальные секции — в исходном виде из редизайна, ждут доработки.

Порядок секций на странице:
`бегущая строка → хэдер → герой → тёмная «Десять вкусов» → сетка «Все вкусы» (10 SKU) →
«Почему OFF Сянка» → «Три шага» → набор −25% → подписка −10% → футер (красный)`.

## 🔧 Что изменилось (по шагам)
- Установлен скилл **ui-ux-pro-max** (`.claude/skills/`).
- Полный редизайн `index.html` в стиле Gigantic; токены вынесены в `tokens.css`.
- Тёмная секция: halftone-текстура + рваные края (torn-paper) сверху/снизу.
- **Логотип**: извлечён из присланного PNG (был непрозрачный фон-шахматка), векторизован в SVG
  (vtracer), перекрашен в ink, увеличен ~2× (88px десктоп / 60px мобайл), в левом верхнем углу.
- **Хэдер**: двухрядное основное меню.
  - Ряд 1: Логотип · Вкусы · Производство · Сотрудничество · О нас · [бургер] · **Заказать**.
  - Ряд 2 (по бургеру): Почему OFFсянка · Мы в Соцсетях · Где Купить · Контактные Данные.
  - Иконка бургера переключается icon-open ⇄ icon-close; `aria-expanded`.
  - Старый поиск и старый мобильный бургер удалены.
  - Второй ряд начинается под началом «Вкусы»; линия-разделитель во всю ширину (logo→правый край).
- **Иконки бургера**: загружены пользователем (PNG), убран непрозрачный фон (flood fill → прозрачность).
- **Бегущая строка**: 4 фразы с красными точками — «25 г белка в одной упаковке», «10 ярких вкусов»,
  «без сахара · без варки», «5 минут — и готово» (продублированы для бесшовной петли).
- **Герой**: новый подзаголовок; одна кнопка «Выбрать вкус» → `#flavors`; кнопка «Как это работает»
  убрана; анимация появления при загрузке (stagger, ease-out, учитывает `prefers-reduced-motion`).
- **Тёмная секция**: подзаголовок обновлён; пакет поднят ~на 1 см от низа; **авто-карусель** всех
  10 вкусов (слайд влево, 1.5с/вкус, бесшовная петля 15с, CSS `@keyframes`); пауза вне экрана
  через `IntersectionObserver`.

## ⚠️ Что пробовал и НЕ сработало
- **Нет браузера для рендера/скриншотов**: загрузка Chromium (Playwright CDN) и `apt` заблокированы
  сетевой политикой. Превью делаются через **WeasyPrint** (HTML→PDF→PNG), и он МНОГОЕ не умеет:
  - CSS-анимации (бегущая строка, карусель, появление героя) — рендерит один статичный кадр;
  - flex-карусель пакетов (`width:1100%` + проценты + `object-fit`) — в превью пустая;
  - `position:absolute` + media-queries — мобильные/выпадающие состояния показывает неверно;
  - `onerror`-фолбэки картинок (PNG→SVG) — не выполняет JS, показывает alt-текст.
  → Для проверки анимаций/мобайла нужен реальный браузер (`python3 -m http.server`).
- **framer-motion** установлен (`npm i`), но **не используется**: проект — статический HTML, а это
  React-библиотека. Лежит в `package.json` как мусор; можно удалить.
- **Линия-разделитель во 2-м ряду через `margin-left:-Npx`/`padding-left`** — ненадёжно: линия не
  доходила до логотипа и съезжала вправо (смещение зависит от ширины логотипа/стека). Заменено на
  отдельный элемент `.nav-sep` с `::before { right:100%; width:100vw }`, обрезаемый `.nav { overflow:hidden }`.
- Скилл **ui-ux-pro-max** ссылается на `scripts/search.py`, которого нет в репозитории апстрима —
  скилл по сути docs-only (работает как справочник, без автоматизации).
- Загрузки файлов из чата: картинки, присланные в чат, как файлы недоступны — логотип и иконки
  пользователь докидывал в репозиторий через GitHub (иногда с искажёнными именами — приходилось
  переименовывать/обрабатывать).
